# Changelog

## 0.1.0

First release.

- `ConfigProvider`: mode (dark / light / system), accent and custom tones, token overrides, density, platform, motion, locale (English and Indonesian), default props per component; nests.
- Foundation, inputs, layout, display, tiles & data, overlays & feedback, navigation and mobile components (see the README for the list).
- `/motion`: Metro curves, variants and `useTween` (easing-utils).
- `/hooks`: library hooks and a curated set of `@mantine/hooks`.
- Docs site with live examples, props tables, a theme builder and a playground.
